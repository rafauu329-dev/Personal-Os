# PERSONAL-OS 🧠

A powerful browser-based personal productivity dashboard designed to help manage daily life, work, goals, and self-growth — all in one place.

Built with **HTML, CSS, and Vanilla JavaScript**, PERSONAL-OS acts like a lightweight personal operating system for productivity, organization, and reflection.

---

## ✨ Overview

**PERSONAL-OS** is a front-end productivity web app that centralizes multiple self-management tools into one clean interface.

It helps users organize:
- Daily schedules
- Projects
- Goals
- Journals
- Habits
- Money tracking
- Reviews
- Productivity tools

A minimal and interactive dashboard made for personal use, focus, and life organization.

## ⚙️ How It Works

The app uses a modular structure where each major productivity area is separated into independent components.

Core logic handles:
- UI rendering
- State updates
- Data handling
- Module switching
- Reusable utilities
- Local interactions

This makes the project scalable and easy to maintain.
